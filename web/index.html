How this works

The three methods

No-change guess

For: a baseline to beat.

How: assumes the price stays where it closed today. If a model cannot beat this, its forecasts add nothing.

Ridge regression

For: a simple, transparent model.

How: adds up the inputs with learned weights (a straight-line model). A penalty keeps the weights small so it does not chase noise.

Gradient boosting

For: patterns that are not straight lines.

How: builds 200 small decision trees one after another; each new tree corrects the errors of the ones before it.

Inputs: "Own price" = the stock's past returns, volatility, moving averages, and trading volume. "+ Market" adds S&P 500 (SPY) returns and volatility. "+ Company filings" adds revenue growth, profit margin, earnings per share, debt ratio, and days since the last report. Every model predicts the change from today's close.

Training and testing

The data is split by time, never shuffled: the model learns only from the past and is tested on a later period it has never seen. The gap keeps training outcomes from overlapping the test period. After testing, the model is retrained on all data up to today to make the forecast.

Where the data comes from

DataSourceHow it is collected
Daily prices and volumeYahoo Finance (backup: Stooq) The yfinance Python library requests Yahoo's public data service; if that fails, a CSV file is downloaded from Stooq. Prices are adjusted for stock splits and dividends.
Market (S&P 500)Yahoo FinanceSame as prices, using the SPY index fund.
Company filingsSEC EDGAR (U.S. Securities and Exchange Commission) The SEC's official, free data API (XBRL "company facts") returns numbers from quarterly 10-Q and annual 10-K reports. Each number is used only from the day after it was filed.

No web pages are scraped: all data comes from data services that return structured files (JSON or CSV). Updates are automatic. A scheduled job on GitHub runs every weekday after the U.S. market closes (about 6:30 pm New York time): it downloads the new data, retrains all models, saves the forecasts, and this site updates within minutes.

Built for teaching. This is not investment advice. Future events can change prices in ways no model can see, so use these numbers to stay informed, not to trade.

Prices: daily closes (split and dividend adjusted). Company numbers: SEC EDGAR filings.
